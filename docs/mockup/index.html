Mockup statis lebar 390px: beranda, ujian, hasil, dan leaderboard. Geser tiap baris ke samping untuk melihat keempat layar. Data, nama peserta, dan skor di sini hanya contoh.

Halaman ujian sengaja dibuat hampir sama di ketiga arah: tenang, kontras tinggi, dan mirip CAT. Yang berbeda hanya beranda, hasil, dan leaderboard.

A · Buku Catatan Rapi B · Map Arsip Taruna C · Buku Tempel Misi

A. Buku Catatan Rapi (paling aman)

Halaman buku petak yang bersih. Kartu bertepi tinta dengan bayangan tegas, satu stiker atau stempel per layar, coretan tangan hanya untuk catatan kecil dari "kakak tingkat".

Font: Poppins 800 untuk judul, Poppins untuk isi, Space Mono untuk label, Kalam untuk coretanLatar: kertas petak 22pxMood: rapi, ramah, bisa dipercaya orang tua

B. Map Arsip Taruna (tengah)

Diambil dari dunia asrama dan administrasi: kertas bergaris dengan garis margin merah, map bertab, penjepit kertas, nilai ditulis seperti buku besar, dan stempel ganda. Judul memakai Archivo yang dipersempit sehingga mirip label map.

Font: Archivo sempit 800–900 untuk judul (usulan), Poppins untuk isi, Space Mono untuk teks ketikanLatar: kertas folio bergarisMood: serius, disiplin, khas kedinasan

C. Buku Tempel Misi (paling berani)

Seperti buku stiker atau papan misi game. Ada pita cokelat dengan sinar seperti foto profil B, stiker bertepi putih yang dimiringkan, angka skor besar dengan font Bowlby One, medali, dan streak. Keramaiannya berhenti di halaman ujian.

Font: Bowlby One untuk judul dan angka (usulan), Poppins untuk isi, Space Mono untuk chip, Kalam untuk coretanLatar: krem polos + pita sinarMood: seru, kompetitif, cocok untuk konten TikTok
